# 小说创作工作台

一个面向长篇小说创作的本地优先工作台，覆盖从灵感、设定、建书到正文落稿的完整过程。作品资料保存在当前浏览器中，AI 生成内容默认先进入预览，确认后才会写入作品。

## 核心功能

- **作品书架**：新建、导入、导出、搜索和整理作品，管理章节、正文与章节提纲。
- **作品资料库**：集中查看和编辑世界观、人物设定、时间线与剧情规划，资料会自动带入相关生成任务。
- **工作流建书**：按创作方向、故事骨架、人物世界、确认建书四步完成新书。创意、大纲、世界观和人物都可以由 AI 辅助生成，并在采纳前编辑。
- **正文创作**：按章节提纲、前文和作品资料生成续写或重写候选；支持多候选保存、差异对照、修改后采纳和版本恢复。
- **AI 共创对话**：可直接请求正文、世界观、人物设定和后续剧情方案，生成结果可以预览后写入章节或资料库。
- **资产库**：统一查看灵感和拆书资产；拆书得到的行文节奏、人物设定、世界观、剧情节点与写作技巧支持搜索、筛选、复制和带入建书。
- **竞品拆书**：导入 TXT，提取章节细纲、节奏节点、人物关系、设定和写作技巧；扫榜详情可以直接把榜单书籍带入拆书流程，并尝试读取公开书籍页面。
- **扫榜分析**：保存公开榜单快照，查看名次变化、分类分布、标签趋势、竞品和作者走势；每本榜单书籍都可以直接进入拆书。
- **写作辅助**：查找替换、专注模式、字号调整、章节字数目标、每日统计和连续写作记录。
- **备份导出**：备份作品、设定、灵感、建书记录、统计、拆书库和榜单快照；正文可导出为 TXT 阅读稿。

## 大模型支持

模型管理支持多个模型档案，可分别保存服务商、Base URL、模型 ID、API Key、上下文上限、输出上限、思考模式和额外 JSON 参数。

内置 OpenAI、DeepSeek、通义千问、火山方舟、智谱、硅基流动、OpenRouter、MiniMax、Gemini 兼容、xAI、本地部署、自定义接口和 Agnes AI 等预设。OpenAI 是新建配置时的默认服务商，Agnes 需要手动选择。

写作助手和工作流建书可以使用不同的默认模型。模型设置提供连接测试和模型列表拉取，并会按服务商转换思考参数；浏览器直连时，服务商需要允许跨域请求。

## 快速开始

```powershell
pnpm install
pnpm dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:6790`。生产构建使用：

```powershell
pnpm run build
pnpm run preview
```

## 数据与隐私

- 作品和模型配置保存在当前浏览器的 `localStorage` 中，不会自动上传到服务器。
- API Key 用于浏览器直连模型服务；导出完整备份时可能包含模型密钥，请妥善保管。
- 清理浏览器站点数据前，请先下载完整备份。

## 当前限制

- 当前是浏览器版本，尚未提供桌面容器。
- 如果模型服务商不允许浏览器跨域访问，连接和生成会失败，需要使用允许跨域的接口或后续接入桌面网络层。
- 逐章生文需要作者逐章确认，暂不提供无人值守批量生成。
- 榜单抓取依赖平台公开页面和接口，平台结构变化可能导致抓取失败。

## 开发预览

开发服务启动后，可以访问 `http://127.0.0.1:6790/?ui-preview=1` 查看带样例数据的界面；使用 `panel=shelf`、`panel=workflow`、`panel=production`、`panel=breakdown` 或 `panel=rank` 可查看对应页面。预览数据只用于展示，不会写入本机作品。
