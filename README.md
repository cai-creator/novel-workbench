# 新小说创作工作台（独立项目）

这是根据旧版功能盘点新建的独立项目。代码与数据结构均从零开始，旧版保留在旁边的 `easy-writing` 目录供参考。[旧版全部功能清单](./FEATURE_INVENTORY.md)。

## 当前可用

- 完整作品书架：搜索和排序作品、查看章节与字数概览、一键回到最近写作的章节。支持新建、切换、删除作品；新建、切换、删除章节；编辑正文与章节标题；导入和导出新版 JSON 作品文件。
- 故事概念，以及可在写作页右侧切换查看的作品资料库（世界观、人物设定、时间线、剧情规划）；正文与资料自动保存在本机浏览器。
- 章节版本历史：手动留存当前稿，AI 写入正文前自动保存原稿；可以预览和恢复，历史随作品 JSON 导出。
- 四步工作流建书：创作方向、书名与章节规划、世界与人物、确认建书。AI 内容先预览再采纳；支持多份草稿、建书历史、继续编辑、复制方案及 JSON 导入导出，建书后自动生成章节提纲与作品资料。
- 逐章生文：按章节提纲、设定和上一章结尾生成正文候选；候选可修改并跨刷新保留，采纳后才写入章节，原稿自动进入版本历史。候选稿随作品 JSON 备份。
- 配置兼容 Chat Completions 的模型，按“正文 / 世界观 / 人物 / 剧情”生成内容。
- AI 结果先预览修改，再采纳到章节或设定库；作品可以导出为 JSON。

## 启动

在本目录执行 `pnpm install`、`pnpm dev`，浏览器访问终端显示的地址（默认 127.0.0.1:6790）。项目已声明允许 Vite 所需的 `esbuild` 构建脚本；如本机策略仍拦截，请按 pnpm 的错误提示批准该依赖。

## 界面设计预览

新版采用“连载创作室”视觉方案，规则与页面结构见 [UI 设计说明](./UI_DESIGN.md)。开发服务启动后，访问 `http://127.0.0.1:6790/?ui-preview=1` 可查看带样例内容的写作页；加上 `&panel=shelf` 可查看作品书架，`&panel=workflow` 可查看建书流程，`&panel=workflow-history` 可查看建书记录，`&panel=production` 可查看逐章生文，`&panel=reference` 可查看作品资料，`&panel=preview` 可查看 AI 内容采纳弹窗。样例只在开发环境显示，不保存到本地作品。

## Agnes 3.0 Flash

在“模型设置”中点击 Agnes 预设，填写 API Key 后点击“测试连接”。预设使用 [Agnes 官方文档](https://agnes-ai.com/zh-Hans/docs/agnes-30-flash)列出的 `https://apihub.agnes-ai.com/v1` 和 `agnes-3.0-flash`。生成失败时，建书草稿和原有作品不会被覆盖；错误会显示在当前步骤。尚未使用真实 Agnes 账号和密钥做端到端验证。

## 当前限制

- 第一版是浏览器版；还没有 Tauri 桌面打包。数据保存在当前浏览器的 localStorage，清理站点数据前请分别导出作品和建书记录。建书记录备份不包含小说正文，导入完成记录后需单独导入对应作品。
- 模型在浏览器中直连服务商。若服务商不允许网页跨域访问，需在后续桌面版接入原生网络层。当前未对 Agnes 做真实账号调用验证。
- 此版本暂不读取旧版数据库，避免误改旧版作品；导出 JSON 是新版格式。
- 建书工作流已实现可编辑的四步流程与多份记录；逐章生文目前需要每章手动生成和采纳，尚无无人值守批量任务或 AI 候选并排对比。旧版的榜单、拆书、每日写作统计与图片生成仍未实现。当前章节历史保留最近 30 个版本，尚无逐字差异对比。
