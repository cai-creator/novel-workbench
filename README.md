# 新小说创作工作台（独立项目）

这是根据旧版功能盘点新建的独立项目。代码与数据结构均从零开始，旧版保留在旁边的 `easy-writing` 目录供参考。[旧版全部功能清单](./FEATURE_INVENTORY.md)。

## 当前可用

- 完整作品书架：搜索和排序作品、查看章节与字数概览、一键回到最近写作的章节。支持新建、切换、删除作品；新建、切换、删除章节；编辑正文与章节标题；导入和导出新版 JSON 作品文件。
- 故事概念，以及可在写作页右侧切换查看的作品资料库（世界观、人物设定、时间线、剧情规划）；正文与资料自动保存在本机浏览器。
- 章节版本历史：手动留存当前稿，AI 写入正文前自动保存原稿；可以预览、与当前稿对比文字差异和恢复，历史随作品 JSON 导出。
- 四步工作流建书：创作方向、书名与章节规划、世界与人物、确认建书。AI 内容先预览再采纳；支持多份草稿、建书历史、继续编辑、复制方案及 JSON 导入导出，建书后自动生成章节提纲与作品资料。创意、章节规划、世界观、人物四个字段都能按类型从竞品拆书库带入素材，带入前可自行增删修改。
- 逐章生文：按章节提纲、设定和上一章结尾生成正文候选；可以选择续写或从头重写，同章保留多份候选，查看与现稿的文字差异、修改、删除并择优采纳。原稿自动进入版本历史，未采纳候选随作品 JSON 备份。
- 写作统计：今日字数与连续写作天数、累计字数与 AI 采纳占比、每日目标进度、近 7/15/30 天趋势，以及可按作品筛选的码字日历。只统计净增的正文字数，删除不计入。
- 灵感收集：随手记录一句话想法，支持标签、置顶、按标签筛选、编辑、删除，并可把灵感送进建书流程作为起点。
- 竞品拆书：导入整本 TXT 后逐章拆解细纲、关键节点、爽点节奏、世界观设定与人物关系，前三章附带黄金三章深拆，全部拆完生成全书报告；拆解产物按人设、节奏、设定、节点、技巧五类分开存成素材库，可在工作台按类查看、按类复制，也能按类带进建书流程的对应字段。
- 扫榜：抓番茄、七猫的公开榜单存成本机快照，看名次变动、分类分布、标签风向、竞品跟踪与作者趋势，也能把手里的榜单页 HTML / 接口 JSON 粘进来导入；支持存档导入导出、CSV 导出与 AI 解读。
- 编辑器增强：查找与替换（区分大小写、逐处跳转、全部替换）、本章字数目标与完成提示、正文字号调节、专注模式，以及保存版本和查找的键盘快捷键。
- 备份与导出：一键下载包含全部作品、章节、设定、灵感、建书记录、写作统计，以及扫榜快照和竞品拆书库的全量备份；恢复时可选择合并（只添加本地没有的内容）或覆盖。正文可导出为 TXT 阅读稿。
- 配置兼容 Chat Completions 的模型，按“正文 / 世界观 / 人物 / 剧情”生成内容。
- AI 结果先预览修改，再采纳到章节或设定库；作品可以导出为 JSON。
- 移动端适配：窄屏下顶栏收起为菜单，书架与章节目录改为横向滑动，正文、查找栏与弹窗均为触屏重排；触屏上选中正文即可唤出润色、扩写、纠错与自定义修改菜单，触屏聚焦输入时不会触发系统误缩放。

## 自测

`pnpm test` 运行零依赖的逻辑测试，覆盖文本差异对比、存储与数据迁移、写作统计、建书流程解析，以及拆书页解析、分类素材聚合与扫榜快照的存取、聚合和榜单页解析；`pnpm build` 在打包前用 vue-tsc 对源码和测试做严格类型检查。


## 启动

在本目录执行 `pnpm install`、`pnpm dev`，浏览器访问终端显示的地址（默认 127.0.0.1:6790）。项目已声明允许 Vite 所需的 `esbuild` 构建脚本；如本机策略仍拦截，请按 pnpm 的错误提示批准该依赖。

## 界面设计预览

新版采用“连载创作室”视觉方案，规则与页面结构见 [UI 设计说明](./UI_DESIGN.md)。开发服务启动后，访问 `http://127.0.0.1:6790/?ui-preview=1` 可查看带样例内容的写作页；加上 `&panel=shelf` 可查看作品书架，`&panel=workflow` 可查看建书流程，`&panel=workflow-history` 可查看建书记录，`&panel=production` 可查看逐章生文，`&panel=production-compare` 可查看候选与现稿的文字差异，`&panel=history-diff` 可查看历史版本差异，`&panel=reference` 可查看作品资料，`&panel=preview` 可查看 AI 内容采纳弹窗，`&panel=breakdown` 可查看竞品拆书，`&panel=rank` 可查看扫榜。样例只在开发环境显示，不保存到本地作品。

## 模型管理与服务商

新版模型管理参考旧版的多模型配置能力，支持 OpenAI、DeepSeek、通义千问、火山方舟、智谱、硅基流动、OpenRouter、MiniMax、Gemini 兼容、xAI、本地部署和自定义 OpenAI 兼容接口。每个模型可以单独保存 API 地址、模型 ID、上下文上限、输出上限、思考模式和额外 JSON 参数，并提供连接测试与 `/models` 模型列表拉取。

写作助手和工作流建书可以分别指定默认模型；生成调用会按服务商转换思考参数，并兼容 OpenAI 推理模型的 `max_completion_tokens`。初始模型表单默认 OpenAI，Agnes 仅作为手动选择的可选服务商，不再默认写入。浏览器直连服务商时仍需确认接口允许跨域访问。

## 当前限制

- 第一版是浏览器版；还没有 Tauri 桌面打包。数据保存在当前浏览器的 localStorage，清理站点数据前请先下载全量备份。备份文件里会写入当前模型密钥，请只保存在自己信任的地方；建书流程本身也可以单独导出记录，但记录不包含小说正文，导入完成记录后需单独导入对应作品。
- 模型在浏览器中直连服务商。若服务商不允许网页跨域访问，需在后续桌面版接入原生网络层；连接测试和模型列表拉取只能验证当前接口与账号的实际返回。
- 此版本暂不读取旧版数据库，避免误改旧版作品；导出 JSON 是新版格式。
- 建书工作流已实现可编辑的四步流程与多份记录；逐章生文目前需要每章手动生成和采纳，尚无无人值守批量任务。文字差异会高亮小范围修改；对比超长且大幅改写的段落时，可能按整段标记。旧版的提示词管理与图片生成仍未实现。当前章节历史保留最近 30 个版本，写作统计保留最近 400 天。
- 扫榜与拆书读的是平台公开页面：番茄页面用私用区字体做了反爬混淆，抓取靠内置字典解码，平台换字体时会中止并提示，而不是把乱码存进快照；七猫走公开接口。同一榜单同一天 30 分钟内重复抓取会直接用已存数据，避免把接口打爆。抓取请求在开发与预览服务里都经过域名白名单代理转发，只放行番茄与七猫两个域名。
